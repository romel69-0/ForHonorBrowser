# Changelog

## 1.1.0

- Each tint colour has a **Shiny** switch: polished metal finish, or plain flat colour.

## 1.0.0

First public release.

- Hero browser: 46 hero groups, about 1,770 outfits, in-game hero names.
- Mix helm, chest and arms from any outfit of a hero.
- Colour tinting from the armour colour masks, and metal material presets.
- Search of all ~48,000 models (weapons, ornaments, props).
- Export: one customized `.glb`, or original parts with full-size textures.
- Game folder auto-detection, folder picker, and automatic re-index after game updates.
